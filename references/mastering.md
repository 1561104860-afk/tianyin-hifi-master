# 母带处理：响度、音色与低/高频

## 三个客观指标

| 指标 | 含义 | 安全区 |
|---|---|---|
| **LUFS**（集成响度） | 人耳感知的平均音量 | 流媒体 −14；商业流行 −9 ~ −11 |
| **dBTP**（真实峰值） | 含采样间峰值的数字上限，>0 会削波 | ≤ −0.3，理想 −1.0 |
| **LRA**（响度范围） | 动态起伏，越小越「压平」 | ≥ 3.5；掉到 3 以下就是压过头、听感发糊 |

测量（EBU R128）：

```bash
ffmpeg -hide_banner -i "<音频>" -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null -
```

### 实测案例：某首 48kHz/24bit 天音母带

| 版本 | LUFS | dBTP | LRA | 听感 |
|---|---|---|---|---|
| 原始母带 | −13.59 | **+0.09** | 4.4 | 偏轻，峰值已顶满 |
| 纯 `loudnorm I=-10` | −10.44 | −0.72 | **3.1** | 响但**糊**（限幅过狠压平瞬态） |
| `hifi` 全频段版 | −11.02 | −0.41 | **4.1** | 通透、动态保住 |
| 第三方去 AI 化处理版 | −9.07 | +1.46 | 2.9 | 暖厚、更响但更平 |

**教训**：峰值已顶满 0 dBFS 的母带，想更响只能牺牲动态。`hifi` 版故意只做到 −11 LUFS、LRA 8 目标，保留瞬态；「更响」需求交给独立的「加音量」版，不要叠加。

## 分频段处理链（默认 hifi）

```
highpass=f=20,
equalizer=f=80:width_type=o:width=1.0:g=+1.0,       低频厚度
equalizer=f=320:width_type=o:width=0.8:g=-2.5,      低中频去糊
equalizer=f=2500:width_type=o:width=1.0:g=+0.8,     中频音色/存在感
treble=g=+3.5:f=9000,                                高频清晰度
equalizer=f=12000:width_type=o:width=1.5:g=+2.0,    空气感
equalizer=f=18000:width_type=o:width=1.0:g=-1.5,    超高频整形
extrastereo=m=1.20,                                  mid/side 声场加宽
loudnorm=I=-11:TP=-1.0:LRA=8
```

### 各频段的作用与安全区间

| 参数 | 频段 | 默认 | 建议区间 | 过头会怎样 |
|---|---|---|---|---|
| `--low` | 80Hz | +1.0 | 0 ~ +3 | >+4 轰头、掩蔽人声 |
| `--mud` | 320Hz | −2.5 | −4 ~ 0 | <−5 声音变薄、失去温暖 |
| `--mid` | 2.5kHz | +0.8 | −1 ~ +2 | >+3 刺耳、电话音 |
| `--pres` | 9kHz 高架 | +3.5 | +1.5 ~ +5 | >+6 齿音重、毛躁 |
| `--air` | 12kHz | +2.0 | 0 ~ +3 | >+4 沙沙的假高频 |
| `--tilt` | 18kHz | −1.5 | −3 ~ +1.5 | 正值更亮更开阔但可能毛刺；负值耐听但偏闷 |
| `--width` | mid/side | 1.20 | 1.0 ~ 1.35 | >1.4 相位问题、单声道兼容变差 |
| `--target-lufs` | 响度 | −11 | −12 ~ −9.5 | 推到 −9 以下会压糊 |

**注意**：`stereotools` 不支持 `mode`/`side_gain` 这类参数（实测报错），用 `extrastereo=m=` 才可靠。

## 音色迁移（`--tone-ref`）

用途：让完整母带的 tonal balance 贴近另一份参考音频（例如另一份成品的暖厚质感）。

原理：
1. 两版都解码为 44.1kHz 立体声 f32，取 1.5 秒步长窗口做 4096 点 Hann FFT，得到长期平均功率谱 `Pa`（目标）与 `Pr`（参考）。**跳过静音/掉字窗口**，否则参考音频里的静音段会污染统计。
2. 在 1/3 倍频程中心频点上算 `10*log10(Pr/Pa)`；**减去中位数**（整体电平差），只保留相对频谱形状——音量由后面的 `loudnorm` 负责，不能把「参考版更响」误当成「所有频段都要 +5 dB」。之后 clamp ±5 dB 并做三点平滑。
3. log 频率线性插值 + 9 点平滑，得到目标频响 `H(f)`。
4. **零相位 OLA 频域滤波**（N=4096 / hop=2048 / Hann / COLA 归一化）应用到目标音频；峰值 >0.98 时整体缩放保护。

特点：不改变时间轴、不改变音高、不引入拼接，因此不会造成节奏卡顿。只迁移**相对频谱包络**，不迁移混响、人味、空间信息或整体音量。需 numpy（`pip install numpy`）；用任一装了 numpy 的 Python 解释器运行即可。参考音频尽量用**整首**——短片段（20 秒）统计噪声大，曲线会锯齿化。

**排错**：若打印的音色曲线几乎全是 ±5 dB（打满上限），说明整体电平差没扣干净或样本量不足；检查参考音频是否有效、是否够长。

实测迁移曲线（第三方处理版 vs hifi 母带）：低频 63~400Hz +2~5 dB、16kHz 以上 −5 dB——即参考版更暖更厚、超高频收敛。

## 预设

| 预设 | low | mud | mid | pres | air | tilt | width | LUFS | 适用 |
|---|---|---|---|---|---|---|---|---|---|
| `hifi` | +1.0 | −2.5 | +0.8 | +3.5 | +2.0 | −1.5 | 1.20 | −11 | 默认，通透均衡 |
| `warm` | +2.5 | −2.0 | +0.5 | +1.5 | +0.5 | −3.0 | 1.15 | −9.5 | 暖厚人味 |
| `air` | +0.5 | −3.0 | +1.5 | +4.5 | +3.0 | +1.0 | 1.30 | −11 | 更亮更宽，场域感 |
| `loud` | 0 | 0 | 0 | 0 | 0 | 0 | 1.00 | −10 | 只加音量，不改音色 |
| `flat` | 0 | 0 | 0 | 0 | 0 | 0 | 1.00 | −11 | A/B 基准 |

参数显式传入时覆盖预设对应项，其余保留预设值。

## 硬限制（要对用户如实说明）

- 源是 48kHz/24bit 母带，最高频率 24kHz。**升采样不会凭空长出新频率**，「真 Hi-Res 超高频」变不出来。
- AI 干声没有录进真实房间混响。EQ 提亮 + `extrastereo` 加宽只是**听感上更开更立体**，不是真实空间感；真实场域感需要卷积混响（属改混音，不是修母带）。
- 原始母带被删掉的旋律段落，任何拼接/变速/循环补法都取不回来，且会破坏节奏网格：实测把缺口前后 6.4 秒拼接后 `atempo≈0.91` 慢放撑满 7 秒，每 8 秒一次局部减速 + 跳过 0.6 秒内容，30 处接缝产生明显卡顿。**正确解法是拿完整母带重新过一遍工具**。

## 交付前验证清单

```bash
ffmpeg -hide_banner -i "<成品>" -af silencedetect=noise=-40dB:d=0.15 -f null - 2>&1 | grep silence_start
ffprobe -hide_banner "<成品>" 2>&1 | grep -E "Duration|Audio"
```

- 时长与原始母带一致；中段无新增静音（只剩开头 ~0.2 秒自然引子属正常）。
- dBTP ≤ 0；LRA ≥ 3.5；FLAC 头 `fLaC`；24bit WAV 用 `pcm_s24le`，工具输入用 44.1k/16bit `pcm_s16le`。
- 原始母带保持不动；同一目录里别混放同一首歌的多个变体（部分工具会自动挑「最新一个」导致选错）。
